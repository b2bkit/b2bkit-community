# B2BKit community

Public home for [B2BKit](https://b2bkit.dev): a Next.js + Hono + Expo monorepo for B2B SaaS on web, iOS and Android.

The kit's source code is private and shared with customers. This repository holds everything public:

- **[Roadmap](ROADMAP.md)**: what's being built and what's next.
- **[Changelog](CHANGELOG.md)** and [Releases](https://github.com/b2bkit/b2bkit-community/releases).
- **Issues**: bug reports and module requests.
- **Discussions**: questions, ideas, showcase of what you built.

Want early access? Join the waitlist at [b2bkit.dev](https://b2bkit.dev).
