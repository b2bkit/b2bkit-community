# Roadmap

A module joins the roadmap when at least three customers ask for it, or when it was already built in a paid client project.

## Now: core (private beta)

- [x] Monorepo: Turborepo + pnpm, Next.js web, Hono API, Expo mobile
- [x] Auth with organizations, roles and invitations on web and mobile
- [x] Typed API client shared by web and mobile
- [x] AI agent rules: AGENTS.md, CLAUDE.md, Cursor rules, first recipe
- [ ] Billing shared by web and mobile
- [ ] Admin panel and email templates
- [ ] Docs: quick start in 5 minutes
- [ ] Live demo: web, TestFlight, APK

## Next: launch

- [ ] Automatic access after purchase (GitHub invite + license key)
- [ ] `create-b2bkit` CLI with module selection

## Later: depending on demand

- Mobile: push notifications, in-app purchases, EAS build and store publishing guide
- Desktop app (Tauri) around the web app
- i18n, file storage, notifications, analytics, AI integrations
